These are the exact scripts used to produce the results, figures and spreadsheet of the article.
They were run from the project root with the raw data loaded into data/v12.pkl (same content as data/barcarena_2018_wells.csv)
and write to data/ and figs/. Order: model_final.py -> sensitivity.py -> fig_*.py.
For new applications use the ipa package (ipa/core.py) instead.
